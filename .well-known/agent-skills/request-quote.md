# TKC Talent — Request a celebrity booking quote

## Required information

Collect from the user before handing off:

- Artist(s) of interest (name or category, e.g. "A-list Bollywood singer")
- Event date (or date range)
- Event city / venue
- Event type (wedding, sangeet, corporate annual day, brand launch, concert, digital campaign)
- Expected audience size
- Budget band (optional but speeds up the quote)
- Requester name, company (if any), phone, email
