# Project rules
- Priority SEO pages (event management hub, Delhi/Gurgaon/wedding planner pages, and edits to celebrity/corporate pages, sitewide footer links) are generated by `scripts/priority-keyword-fix.py` from `scripts/priority_pages_content.py` + `scripts/priority_pages_lib.py`; edit the content/lib and re-run (idempotent) instead of hand-editing the output HTML — why: hand edits get overwritten on the next run.
- The static site's compiled stylesheet only contains classes used at build time; new static markup must use existing classes or inline styles/page-level `<style>` — why: unknown Tailwind classes silently do nothing.
